# The-Company-of-Pets
- Author: Yan Zhao 
- Course: 52685 Creative Coding — Assessment 2

## General Information
The Company of Pets is an interactive pixel-art animation made in Processing. Inspired by the experience of returning home to my cat, it explores companionship through a homecoming scene. Mouse clicks guide the sequence, combining character movement, changing poses and sound with a surprise ending.
