# The-Company-of-Pets

- Author: Yan Zhao 
- Course: 52685 Creative Coding — Assessment 2

## General Information

The Company of Pets is an interactive pixel-art animation made in Processing. Inspired by the experience of returning home to my cat, it explores companionship through a homecoming scene. Mouse clicks guide the sequence, combining character movement, changing poses and sound with a surprise ending.

## Project Files

- `The Company of Pets_project/final_work.pde`: contains the code for drawing, mouse interaction, character movement, sound and restarting the animation.
- `The Company of Pets_project/data/`: inside the sketch folder | PNG backgrounds and character images, together with the WAV audio files required by the animation. |
- `README.md`: provides the project overview and instructions for running and using the animation.

## Setup and Run

1. Download and install [Processing](https://processing.org/download), launch Processing and select Java mode. If no sketch editor is open, choose File > New to open a blank sketch. Click the sketch window on the top-left corner to make it active.

2. In Processing, go to Sketch > Import Library > Manage Libraries...
   Search for "Sound" by "The Processing Foundation" and install it.

3. On this repository's main page, click Code > Download ZIP.

4. Extract the ZIP file `The-Company_of_Pets_main` and locate `The Company of Pets_project` folder.

5. Make sure `final_work.pde` and the complete `data` folder are together inside a folder named `The Company of Pets_project`. If necessary, rename the downloaded project folder to match.

6. Open `final_work.pde` in`The-Company_of_Pets_main` in Processing.

7. Click Run to start the animation and turn on your computer's sound.

## Usage
Follow the on-screen prompts. Wait for each movement to finish before continuing to the next interaction.

1. **Click the door.**
   The door opens with a sound, and the person appears at the entrance.

2. **Click the person.**
   The person walks into the room with footsteps, then stops and kneels.

3. **Click the cat when prompted.**
   The cat walks towards the person and meows once as it approaches.

4. **Click the sofa when prompted.**
   The person walks to the sofa and sits. The cat then follows automatically and lies beside them.

5. **Click the lying cat.**
   The cat moves towards the viewer along a curved path, followed by a cat face filling the animation window.

**Restart:** Press **R** key at any stage to stop the sounds and return the animation to its starting state. Make sure the animation window is active before pressing the key.
